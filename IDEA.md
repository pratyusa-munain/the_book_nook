# Website Idea: The Book Nook

**Website name:** The Book Nook

**Purpose:** The Book Nook is a cosy, modern website where users can browse a curated collection of books, search for a title or author, filter by genre, and save books they want to read later.

**Target audience:** Students, casual readers, and book lovers who want a simple way to explore possible reads and keep a personal reading list.

**Design concept:** The site uses a warm cream background, forest-green accents, serif headings, and illustrated book-cover cards. The responsive layout adapts to both desktop and mobile screens.

**Main features:**
- Navigation links to Home, Collection, and About
- Search by book title or author
- Genre filters
- Save/remove books from a reading list
- Browser storage so the reading list remains after refreshing on the same browser
- Responsive mobile navigation

**Technologies:** HTML5, CSS3, JavaScript, and browser localStorage.
